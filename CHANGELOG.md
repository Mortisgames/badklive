# Changelog: upstream ↔ origin

Порівняння вихідного репозиторію `Mortisgames/badklive` (`upstream/main`)
з форком `artBass-rip/badklive` (`origin/main`).

## 2026-09-29 — надійне завантаження даних та офлайн-робота

Базовий коміт upstream: `e0e57ad96812a5761579f4c7f2605f8523007213`.
Коміт реалізації у форку: `0f506924fa21f0bbff77324c985ab68db9f7aa44`.
На момент порівняння upstream не містить комітів, відсутніх у форку.
Нижче перелічені зміни origin відносно цієї бази upstream; додавання цього
changelog є окремою документаційною зміною.

### Завантаження і перевірка даних

- Додано перевірку обов'язкових заголовків CSV, чисел, ймовірностей, дат і
  дубльованих календарних записів із зазначенням листа, рядка та стовпця.
- Незакриті або некоректні лапки CSV відхиляються; підтримуються BOM,
  багаторядкові поля та екрановані лапки.
- Новий знімок усіх семи листів перевіряється до заміни стану. Помилка
  завантаження чи валідації залишає попередній знімок доступним.
- Додано 20-секундний таймаут, скасування решти запитів при помилці й
  об'єднання одночасних оновлень в одну операцію.
- Виправлено читання переставлених стовпців хвиль і тактики.

### Відображення

- Відсутні значення атак зберігаються як невідомі, а не як нулі.
- Календарі вирівнюються за датами; пропущені та неперевірені дні не
  зараховуються як дні без атак у статистиці.
- Додано порожні стани й захист графіків від ділення на нуль.
- Інтерфейс показує час отримання знімка, цільову дату та помилку оновлення.

### PWA і кешування

- Додано версіонований кеш даних із повторною перевіркою при читанні та
  міграцією сумісного кеша v1.
- Усі HTML, CSS, JS-модулі та іконки попередньо кешуються одним комплектом.
- Список ресурсів і версія service worker генеруються за вмістом файлів.
- Оновлення оболонки активується кнопкою з перезавантаженням сторінки.
- Видалення кешів обмежене попередніми випусками поточного scope.
- Оболонка використовує cache-first для узгодженості HTML та модулів;
  запити до зовнішніх джерел service worker не перехоплює.

### Структура і супровід

- Inline CSS і JavaScript винесено в стилі та нативні ES-модулі без
  runtime-фреймворка або збірника.
- `badk-live-dashboard.html` перенаправляє на єдиний `index.html`.
- Додано інструкції локального запуску, перевірок і оновлення PWA.
- GitHub Actions перевіряє PR і main перед публікацією. У Pages потрапляють
  лише файли застосунку, без тестів, node_modules та допоміжних скриптів.

### Перевірка

- 18 модульних тестів: CSV, контракти, календар, атомарність, кеш, таймаути,
  паралельні виклики та service worker.
- 7 браузерних тестів Chromium: вкладки, мобільний екран, помилки джерела,
  офлайн-відновлення, старий URL, оновлення PWA та порожні/нульові дані.
- Перевірки синтаксису, імпортів, manifest і актуальності офлайн-ресурсів.
- Успішний CI та деплой коміту реалізації у форку:
  https://github.com/artBass-rip/badklive/actions/runs/36584648203

Налаштування GitHub Pages і власного домену форка не є змінами коду та не
переносяться до upstream через цей пул-реквест.
